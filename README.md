# Gra_SFML_projekt

Temat projektu: Gra SFML Meteor Dodge
Autor gry: Dominik Słomiński
Opis gry: Meteor Dodge to zręcznościowa gra 2D, w której gracz wciela się w pilota statku kosmicznego, poruszającego się w przestrzeni pełnej niebezpiecznych meteorów. Twoim celem jest przetrwanie jak najdłużej, unikanie kolizji z meteorami. Gracz kontroluje statek za pomocą klawiszy W, A, S, D, umożliwiających poruszanie się w czterech kierunkach.
Statek reaguje płynnie na polecenia, zapewniając intuicyjne sterowanie. 
Meteory poruszają się po ekranie w losowych kierunkach.
Po odbiciu od krawędzi ekranu ich kierunek zmienia się, co utrudnia przewidywanie trajektorii.
